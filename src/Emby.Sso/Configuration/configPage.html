Lets phone and TV apps sign in by sending the password to the provider directly. This path cannot perform multi-factor authentication, and needs a direct-grant authentication flow bound to the provider in Authentik.
Emby's web login page cannot render a custom sign-in button: the login disclaimer is displayed as plain text and the login page's styling is served as an external stylesheet, so neither can inject working script.
